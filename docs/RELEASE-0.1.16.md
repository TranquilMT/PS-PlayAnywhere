# VYNUVO 0.1.16 • Xbox Cloud Gaming

Select **Xbox Cloud Gaming** on the platform hub to open the new Xbox screen. The green player buttons retain the hub’s press animation. The screen scrolls on smaller displays and supports Android Back.

- **Play on Xbox.com** opens the cloud gaming library in an external web handler. Microsoft handles sign-in, catalog access and streaming.
- **Open Better xCloud** launches the installed Android companion. When it is missing, **Get Better xCloud** opens redphx’s official releases. Returning to VYNUVO refreshes the button after installation.
- PlayStation continues to use the native Chiaki console picker. PC / Steam remains marked Coming soon.
- The Android package remains com.tranquil.ps5remoteplay with version code 17. Better xCloud installs separately and retains its own settings.
- Navigation checks cover the hub, Xbox player choices, PC preview and PlayStation picker. Signed-in gameplay requires a compatible account and has not been tested for this release.
