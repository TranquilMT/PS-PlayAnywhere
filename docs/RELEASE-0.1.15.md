# VYNUVO 0.1.15 · Platform hub

## Home and platform selection

VYNUVO opens to three individually labeled platform buttons. PlayStation opens the console picker. Xbox Cloud Gaming and PC / Steam each open their own Coming soon panel. Each button has a distinct icon, accent, press animation and ripple. The layout scrolls on smaller displays.

## PlayStation console picker

Console rows now put the name, address, registration details and current game alongside the console icon. Empty metadata fields collapse. The overflow menu retains the available wake, edit and delete actions. Registration and manual entry remain available from the add button. Android Back and the toolbar arrow return to the platform hub.

## App styling and compatibility

The shared theme, forms, settings, streaming options and playback controls use a darker slate palette with mint accents. The underlying Chiaki streaming and GPU frame-generation paths are unchanged. This Android update uses version code 16 and the existing package and signing identity. Physical-device UI, controller and live console checks remain pending.
